# Отчёт по демоверсии Alingua · 07.11.2026

## Что реализовано
- Оригинальные страницы `index.html`, `parents.html`, `teachers.html` и фирменные CSS.
- Оригинальные локальные шрифты, фотографии из исходников и изображения 66 активных материалов.
- Самостоятельный локальный каталог (`demo-catalog.json`) без серверных API.
- Поиск, фильтры, сортировка, карточки и ссылки на материалы.
- Демонстрационное оформление без настоящих платежей, аккаунтов или заявок.
- Отдельные страницы «О проекте» и «Условия демоверсии».
- Сертификаты с потенциальными персональными сведениями не публикуются (заменены placeholders).

## Проверки
- `node --check demo.js`: пройдено.
- Каталог: 66 опубликованных, 50 английских, 16 китайских; скрытые материалы исключены.
- Правила фильтрации JS: поиск, уровни HSK / A0–C1 и языковые фильтры проверены автоматическим тестом `test_static.js` (локально).
- Ссылки локальных HTML: файлов с отсутствующим путём не обнаружено.
- В JavaScript оставлены только чтения `site-content.json` и `demo-catalog.json` с того же статического хоста.
- Проверка по списку опасных путей: backend, БД, .env, секреты, приватные Miro и Holst URL исключены.

## Ограничения подтверждения
- Запуск браузерной сессии Playwright в текущей среде блокируется корпоративными политиками Chromium (`ERR_BLOCKED_BY_ADMINISTRATOR`), поэтому реальное UI end-to-end тестирование и скриншоты **не выполнены**.
- Публикация через GitHub Pages должна быть проверена после загрузки файлов в репозиторий.
- Изображения из исходного проекта необходимо проверить на право публичного использования владельцем контента.
- Состояние оригинала 25.10.2026 может отличаться от production 07.11.2026.
