# QA — AP Web Portfolio

**Дата:** 7 ноября 2026 г.

## Проверено автоматически в Chromium (локальный HTML в памяти)

- Главная страница и 3 самостоятельных демосайта.
- Ширины **320, 390, 768, 1024 и 1440 px**: **горизонтальной прокрутки нет**.
- Ошибки JavaScript: **не обнаружены**.
- Страница портфолио: 4 карточки проектов, 4 ценовых варианта, выбор тарифа обновляет поле заявки.
- «Лиза. English»: переключение программ, подтверждение демонстрационной заявки.
- «Формула»: интерактивный подбор программы, подтверждение демонстрационной заявки.
- «КЛАСС!»: 8 программ, фильтр китайского (3 результата), поиск по названию, пустые результаты, сброс, открытие карточки, добавление в список, окно выбранных программ, закрытие Escape.
- Все сценарии работают без серверной части.

## Ограничения проверки

- Chromium в данной среде блокирует прямой HTTP/файловый переход; тестирование выполнено через `page.set_content` со встроенными локальными стилями и скриптами. Это подтверждает работу клиентской логики и отображение, но **не заменяет проверку окончательно опубликованной версии по публичной ссылке**.
- Юридическое соответствие реальных форм обработки данных не оценивалось, поскольку демоформы не отправляют данные.
- Настоящий канал получения заказов не подключён: владелец должен указать Telegram/почту.
- Публикация на GitHub Pages будет подтверждена только после запуска скрипта и проверки публичного URL.
