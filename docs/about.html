О ПРОЕКТЕ · ПОРТФОЛИО

Alingua — от идеи до образовательной платформы.

Интерактивная демонстрация сайта репетитора английского и китайского языков. Эта версия воспроизводит интерфейс реального проекта и работает автономно на GitHub Pages.

Образовательный сайт

Главная страница, направления обучения, онлайн-занятия и заявка.

Каталог уроков

66 опубликованных на момент исходного архива материалов с фильтрацией, поиском, карточками и превью.

Рабочий проект

FastAPI, PostgreSQL, Docker Compose, Caddy, Telegram-бот и тестовая интеграция платежей.

Публичная демоверсия

Самостоятельный HTML/CSS/JS-клиент без настоящих платежей, заявок, данных пользователей или доступа к backend.

Архитектура оригинального проекта

Посетитель → веб-интерфейс → защищённый API FastAPI → PostgreSQL; отдельные процессы обслуживают заказы и интеграции. Публичная версия использует только локальный JSON и изображения.

Что можно попробовать

Откройте раздел «Материалы», выберите язык, настройте фильтры, найдите урок, изучите подробное описание и попробуйте демонстрационный сценарий оформления.
