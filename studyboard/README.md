# StudyBoard — учебный планер

Рабочее мини-приложение для предметов, заданий, дедлайнов, статусов, поиска, календаря и прогресса.

Онлайн: https://apestalina-byte.github.io/alingua-demo/studyboard/

Все стили и сценарии встроены в index.html; дополнительных библиотек и сборки не требуется. Для локального запуска достаточно открыть index.html в браузере. Для офлайн-режима и установки на телефон нужен HTTPS (GitHub Pages).

**Важно:** задания хранятся в локальном хранилище браузера (localStorage). Синхронизация между устройствами и аккаунты не реализованы. Сохраняйте JSON-резервные копии через меню приложения. Не выкладывайте такие копии с личными данными в публичный репозиторий.


## Telegram-бот и синхронизация

Реализована необязательная интеграция с Telegram и синхронизация через FastAPI + PostgreSQL. **GitHub Pages не запускает сервер и не отправляет сообщения.** Сервер должен быть отдельно установлен на VPS.

- Документация и Docker Compose: [backend/README.md](backend/README.md)
- Параметры приватного сервера: [backend/.env.example](backend/.env.example)
- Интерфейс подключения: боковое меню StudyBoard → **Синхронизация**
- Привязка: в Telegram отправить своему боту `/start`, затем `/connect`, скопировать одноразовый код в сайт
- 08:00 Москва: ежедневный отчёт, по понедельникам также недельный, напоминания за 3 дня, за день и в день дедлайна

Устройства хранят резервную локальную копию. При первой настройке рекомендуется скачать резервную копию JSON. Бот и сервер не активируются до заполнения секретов и развёртывания на VPS.
