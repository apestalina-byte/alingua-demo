# Alingua Demo

Интерактивная демонстрационная версия образовательной платформы Alingua. Используется исключительно для ознакомления с интерфейсом.

**Демоверсия:** без реальных платежей, сбора персональных данных, доступа к платным материалам и подключений к рабочему API.

Исходные материалы и фотографии публикуются с разрешения их правообладателей.
