# Alingua Demo

Публичная **интерактивная демоверсия** проекта Alingua. Сайт предназначен для знакомства с интерфейсом платформы английского и китайского языков.

**Ссылка после включения GitHub Pages:** https://apestalina-byte.github.io/alingua-demo/

## Возможности

- Адаптивная главная страница и описание направлений обучения.
- Каталог из **20 демонстрационных карточек** материалов.
- Поиск, сортировка, фильтры по языку, уровню и тематике.
- Зависимые уровни: английский A1–C1, китайский HSK 1–6.
- Подробные карточки и имитация оформления заказа без оплаты и передачи данных.
- Работа без фреймворков, серверов и внешних библиотек.

## Безопасность и ограничения

Нет реальных платежей, авторизации, Telegram-бота, API, аналитики, PDF-файлов и обработки персональных данных. Названия и цены материалов иллюстративные и **не являются офертой**. Код не содержит секретов и не имеет доступа к основному серверу.

## Как включить GitHub Pages

Откройте **Settings → Pages**, выберите **Deploy from a branch**, затем **main** и **/(root)**, нажмите **Save**. После публикации проверьте ссылку выше.

Для локальной проверки просто откройте `index.html` в браузере.
