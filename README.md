# Alingua · интерактивная демоверсия

**Публичный интерфейс образовательной платформы на оригинальной дизайн-системе.**

Планируемый адрес: https://apestalina-byte.github.io/alingua-demo/

## Содержимое

- Оригинальный интерфейс: главная страница, занятия, каталог материалов.
- 66 опубликованных материалов (публичные метаданные из снимка исходного проекта 25.10.2026).
- Фильтры по языку, уровню, аудитории, тематике, формату и стоимости, поиск и сортировка.
- Карточки материалов, обзорные изображения, прямые ссылки `teachers.html?material=ID`.
- Интерактивная имитация оформления, формы без реальной отправки.
- Раздел «О проекте» с описанием производственной архитектуры.

## Как это устроено

Статические HTML, CSS, JavaScript и локальный `demo-catalog.json`. Нет связи с `alingua.site` или API, серверных процессов и платёжных запросов. Конфиденциальные материалы, сертификаты, серверные исходники, закрытые ссылки, личные данные и настройки безопасности исключены. Реальные цены могут измениться; информация не является офертой.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000/`. Для работы JSON необходим локальный HTTP-сервер (не `file://`).

## GitHub Pages

Публикация из ветки `main` директории `/(root)` **или** из `main` директории `/docs`, если содержимое проекта скопировано в `/docs`. Главное — не оставлять две несогласованные копии.

## Технологии оригинального проекта

FastAPI, PostgreSQL, HTML/CSS/JS, Docker Compose, Caddy, Telegram-бот, тестовая интеграция ЮKassa. Эти серверные компоненты не включены в открытую статическую версию.

## Правовой статус

Демоверсия предоставлена для ознакомления. Права на материалы и изображения остаются за соответствующими правообладателями. Перед публичным распространением убедитесь в наличии разрешений на фотографии и обложки.
